# Лендинг Атласа метрик

Страница джетметрикс.рф/atlas. Тильда встраивает её iframe'ом с бакета
(`jetmetrics-static/landing/atlas/index.html`, код блока — `site-state/tilda/atlas.html`).

## Правила работы

- **Источник правды — этот репозиторий.** До 05.10.2026 исходник жил только на одной машине,
  в git его не было. `index.html` здесь — точная копия боя на 05.10.2026 (сверено побайтно).
- **Дорабатываем на превью, бой не трогаем.** Превью — GitHub Pages этого репо. Когда новая
  версия согласована, она заливается в бой `deploy.py` на тот же адрес бакета: страницу
  в Тильде трогать не нужно.
- **Правки в бакете руками не делаем.** Иначе бой разойдётся с репо, и следующая заливка
  молча сотрёт правку.

## Превью

- Как на сайте (режим встраивания): https://jetmetrics-io.github.io/atlas-landing/?embed=1
- Целиком, с навигацией по блокам: https://jetmetrics-io.github.io/atlas-landing/

## Как выложить в бой

```sh
python3 deploy.py --dry-run   # чем отличается от боя
python3 deploy.py             # залить; боевая версия сохраняется в .rollback/
python3 deploy.py --rollback  # вернуть прежнюю
```

Ключи — сервисный аккаунт `static-deploy`: `YC_KEY_ID`, `YC_SECRET` в окружении или в
`.deploy.env` рядом (в git не попадает). Нужен `boto3`.
